## 방명록 관리

방명록은 방문자 **각자의 브라우저(localStorage)**에 저장됩니다.  
다른 사람의 메시지는 서로 공유되지 않습니다.

### 메시지 삭제 방법

청첩장과 같은 브라우저에서 **admin.html**을 열어주세요.

- 개별 삭제: 각 메시지 오른쪽 **삭제** 버튼
- 전체 삭제: 상단 **전체 삭제** 버튼

> GitHub Pages로 배포된 경우: `[배포URL]/admin.html`  
> 로컬에서 실행 중인 경우: 브라우저에서 `admin.html` 파일 직접 열기
